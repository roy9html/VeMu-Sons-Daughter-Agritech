# VeMu Sons & Daughters Website

VeMu Sons & Daughters is a Kenyan agricultural company providing innovative solutions to farmers. This project is a simple multi-page website to showcase products, services, customer testimonials, and offer a way for customers to contact the company.

## Project Structure
- `index.html` — Home page
- `about.html` — About Us
- `services.html` — Our Services
- `testimonials.html` — Client Testimonials
- `cart.html` — Product Gallery
- `contact.html` — Contact Page
- `/css/` — Stylesheets (style.css, bootstrap.min.css)
- `/js/` — JavaScript files (bootstrap.bundle.min.js)
- `/images/` — Project images

## Technologies Used
- HTML5 for page structure
- CSS3 for styling
- Bootstrap 5 for responsive design
- JavaScript for interactivity (optional)
- FontAwesome for icons

## Features
- Modern, clean, and mobile-responsive design
- Product gallery and customer testimonial sections
- Contact form ready for integration
- Consistent navbar across pages

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` with a web browser.
4. Use the navigation bar to browse through the website.
